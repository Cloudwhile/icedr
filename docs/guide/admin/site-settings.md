# 站点设置

站点设置用于统一登录页、管理面板和用户界面的身份标识。进入“管理面板 → 系统设置 → 平台配置”进行调整。

## 站点名称与 Logo

- 站点名称应与用户日常识别的服务名称一致。
- Logo 应使用清晰、留白适当的图片，并在浅色和深色背景下检查。
- 修改后同时验证登录页、浏览器标题、管理员页面和移动端。

站点品牌不会替代域名安全。用户仍应通过正式 HTTPS 域名访问，避免在多个相似域名之间切换。

## 语言资源

平台配置可以管理界面语言资源。更新翻译前先确认键名与现有版本匹配，避免上传旧版本资源覆盖新字段。

修改后重点检查：

- 登录和初始化页面。
- 文件操作与冲突提示。
- 分享验证和错误提示。
- 管理设置、审计事件与系统状态。

## 公网地址

使用域名时，公开站点地址、外链地址、OAuth 回调和 Passkey Origin 必须与真实访问地址一致。协议、域名或端口任一不一致，都可能造成登录、分享或 Passkey 失败。

公开地址通常通过部署环境变量提供，详见 [配置说明](/reference/configuration)。

## 系统状态

“系统状态”是管理面板的独立页面，不属于平台配置。它用于查看：

- 当前运行状态和版本。
- Runtime、Node.js、操作系统与架构。
- 进程运行时间和宿主机运行时间。
- 内存使用。
- 存储类型、文件数、已用和可用容量。

系统状态适合确认现象，不替代主机、数据库和对象存储的专业监控。

## 修改后验证

1. 保存设置并刷新页面。
2. 退出登录，检查登录页品牌。
3. 使用桌面和手机宽度检查布局。
4. 创建测试分享，确认页面显示正确站点名称。
5. 查看审计日志，确认配置操作已留下记录。
