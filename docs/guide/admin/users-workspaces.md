# 用户与工作区

当前 Alpha 版本以首个管理员、登录账号、默认工作区和工作区策略为核心。管理概览会显示工作区数量与用量；完整的用户目录、批量导入和工作区生命周期管理尚未作为独立管理页面提供。

## 首个管理员

初始化向导创建的账号拥有管理员权限。上线后应立即：

- 验证管理员邮箱可接收邮件。
- 配置至少一种额外登录或恢复方式。
- 不在共享浏览器中长期保留管理员会话。
- 定期查看管理员登录失败和重新认证事件。

## 新账号来源

账号可以来自本地注册或 OAuth 首次登录，具体取决于认证策略。OAuth Provider 的“允许首次登录自动创建账户”和“可信邮箱关联现有账户”会直接影响账号创建与关联行为。

关闭自动创建前，确认已有用户仍能通过已关联身份登录。允许自动创建时，建议同时要求 Provider 返回已验证邮箱，并限制允许的邮箱域名。

## 工作区

工作区用于隔离文件树、配额和外链策略。管理员概览展示工作区数量；外链设置可以选择工作区并保存对应策略。

当前版本不建议直接修改数据库创建或删除工作区。没有界面支持的数据库写入可能破坏文件、对象和审计记录之间的引用关系。

## 配额层级

上传可同时受到以下限制：

1. 成员配额。
2. 工作区配额。
3. 存储策略上限。
4. 本地磁盘或对象存储物理容量。

最终可上传空间取最先达到的限制。调高工作区配额不会增加物理磁盘容量，也不会自动清理历史版本或回收站。

## 外链工作区策略

管理员可以为工作区设置：

- 匿名访问是公开、邮箱验证还是禁止。
- 邮箱是否允许任意域名或仅指定域名。
- 默认有效期、最大有效期和等待时间。
- 预览、下载、限速和审计范围。

修改策略后，应使用无痕窗口重新验证现有链接。更严格的策略可能立即影响仍在使用的分享。

## 日常检查

- 查看工作区用量和增长速度。
- 检查接近配额的成员和工作区。
- 检查长期有效或访问量异常的分享。
- 检查失败登录、配额拒绝和批量删除事件。
- 确认备份覆盖数据库及全部存储后端。
