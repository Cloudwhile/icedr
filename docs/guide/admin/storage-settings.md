# 存储设置

存储管理分为“存储后端”“存储策略”和“生命周期策略”。三者分别决定文件写到哪里、允许使用多少空间，以及回收站和历史版本保留多久。

## 存储后端

进入“管理面板 → 系统设置 → 平台配置 → 存储后端”，选择本地文件存储或 S3 / MinIO。

### 本地文件存储

- 默认目录是数据目录下的 `local-files`。
- 运行用户必须拥有读写和创建目录权限。
- 数据库与文件目录应放在可备份的持久化磁盘上。
- 系统状态中的可用空间来自宿主机文件系统。

### S3 / MinIO

填写 Endpoint、Region、Bucket、Access Key、Secret Key 和 Path Style 后，先执行连接测试，再保存切换。MinIO 一般启用 Path Style。

详细步骤见 [MinIO / S3 配置](/deployment/minio-s3)。

::: warning 切换只影响新上传文件
本地存储与对象存储之间切换时，已有文件仍留在原后端并继续按原位置读取。切换不是自动迁移。删除旧存储或凭据前，必须完成对象迁移和抽样验证。
:::

## 配额

存储策略可以设置：

- 工作区配额。
- 成员配额。
- 存储策略上限。
- 可选物理容量上限。

系统会同时考虑实际已用空间、历史版本和回收站。配额变更应保留合理缓冲，不要把上限设置为磁盘标称容量的 100%。

## 生命周期

生命周期策略包括：

- 回收站保留天数。
- 历史版本保留数量。
- 历史版本保留天数。

缩短保留期可能使旧内容在下一次清理后不可恢复。修改前先完成备份，并通知受影响用户。

## 容量显示

系统状态会显示存储类型、已用空间、可用空间、文件数和容量检测时间。对象存储没有配置容量指标时，可用空间可能显示未知，这不影响基本文件读写。

容量异常时同时检查：

- 工作区和成员配额。
- 本地磁盘剩余空间或对象存储配额。
- 回收站与历史版本占用。
- 未完成传输和残留对象。
- MinIO / S3 凭据、网络和桶策略。

## 切换前检查

1. 备份数据库与当前存储。
2. 在新后端创建专用账号和私有 Bucket。
3. 通过管理面板连接测试。
4. 切换后上传、预览、下载并删除一个测试文件。
5. 验证旧文件仍可访问。
6. 保留旧后端，直到迁移、校验和恢复演练完成。
