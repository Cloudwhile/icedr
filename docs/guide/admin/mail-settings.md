# 邮件设置

SMTP 用于外链邮箱验证码、密码重置和系统邮件。进入“管理面板 → 系统设置 → 平台配置 → 邮件 / SMTP”进行配置。

## 配置项

| 字段 | 说明 |
| --- | --- |
| SMTP 主机 | 邮件服务提供方给出的服务器地址 |
| 端口 | STARTTLS 常用 `587`，隐式 TLS 常用 `465` |
| 使用 TLS | 必须与端口和服务商要求一致 |
| 用户名与密码 | 建议使用应用专用密码或 SMTP 专用凭据 |
| 发件人名称 | 收件箱中显示的名称，例如 `ICEDR` |
| 发件邮箱 | 应是服务商允许的发件地址 |
| Reply-To | 用户回复时接收邮件的地址，可留空 |

## 推荐配置顺序

1. 在邮件服务商创建专用 SMTP 凭据。
2. 配置发件域名的 SPF、DKIM 和需要的 DMARC 策略。
3. 在 ICEDR 填写 SMTP 参数。
4. 输入测试收件人并发送测试邮件。
5. 确认收件箱、垃圾邮件和邮件头中的发件域名。
6. 测试外链邮箱验证码和密码重置流程。

只有连接测试成功但邮件未到达时，通常需要检查服务商投递日志、发件人授权或域名信誉，而不只是重复保存配置。

## 常见组合

| 类型 | 端口 | TLS 开关 |
| --- | --- | --- |
| STARTTLS | `587` | 关闭隐式 TLS，由连接升级加密 |
| 隐式 TLS | `465` | 开启 |

不同服务商定义可能不同，以服务商文档为准。

## 暂时关闭邮件

不需要邮箱验证或密码重置时，可以关闭 SMTP。关闭后应同步检查外链策略，避免仍强制要求邮箱验证而访客无法收到验证码。

生产环境不要使用仅把邮件内容写入日志的开发投递方式。

## 故障排查

- 连接超时：检查防火墙、出口端口和 DNS。
- 认证失败：检查用户名格式、应用密码和账号 SMTP 权限。
- TLS 错误：检查端口与 TLS 开关组合，以及系统时间。
- 发件人被拒绝：使用服务商已验证的发件地址。
- 验证码频繁失败：检查邮件延迟，同时确认访客没有触发限流。

更多组合问题见 [故障排查](/reference/troubleshooting)。
