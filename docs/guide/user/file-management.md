# 上传与文件管理

ICEDR 的工作区支持列表和卡片视图。文件、文件夹和批量选择共用同一套操作规则；操作是否可用还会受配额、存储状态和管理员生命周期策略影响。

## 上传文件

1. 进入目标工作区和文件夹。
2. 选择“上传”，选取一个或多个文件。
3. 在传输面板查看进度、失败原因或取消任务。
4. 上传完成后刷新列表，确认文件名、大小和修改时间正确。

上传中关闭页面可能中断尚未完成的任务。大文件上传前应确认反向代理没有较小的请求体或超时限制。

## 同名文件处理

同一目录出现同名目标时，界面会提供适用的冲突处理方式：

| 方式 | 结果 |
| --- | --- |
| 跳过 | 保留原文件，不上传冲突项 |
| 覆盖 | 用新内容替换目标文件，不把旧对象作为历史版本保留 |
| 自动重命名 | 为新文件追加序号后保存 |
| 创建新版本 | 保留原内容为历史版本，并把新内容作为当前版本 |

批量上传时，选择的策略会应用到本批次冲突文件。正式覆盖前先确认目标文件和版本保留策略。

## 文件名规则

文件和文件夹名称会移除首尾空白，并按统一字符形式保存。以下名称不会被接受：

- 空名称、`.` 或 `..`。
- 包含路径分隔符、控制字符或 `< > : " / \ | ? *`。
- 以空格或点结尾。
- Windows 保留名，例如 `CON`、`PRN`、`AUX`、`NUL`、`COM1` 到 `COM9`、`LPT1` 到 `LPT9`。
- 超过 255 个字符的名称。

同一目录的名称按大小写不敏感方式检查冲突。例如 `Report.pdf` 与 `report.pdf` 会被视为冲突。

## 常用操作

- 双击文件夹进入，双击文件打开预览或适用的打开方式。
- 使用行尾操作菜单进行重命名、移动、复制、分享、下载或移入回收站。
- 使用复选框选择多个条目，再执行批量移动、下载、恢复或删除。
- 收藏常用文件后，可从“已收藏”快速访问。
- “最近使用”根据近期活动集中展示文件。

## 预览与下载

图片、文本、部分文档和媒体类型可以直接预览。没有预览产物或格式暂不支持时，界面会提示改为下载，不代表原文件损坏。

下载失败时依次确认：

1. 文件没有被移入回收站或永久删除。
2. 当前账号仍有工作区访问权限。
3. 存储后端可访问，且对象没有被外部清理。
4. 反向代理超时和磁盘空间正常。

## 回收站与恢复

移入回收站不会立即永久删除。管理员可以设置回收站保留天数，超过保留期的内容可能由生命周期清理。

恢复时如果原目录存在同名条目，系统会为恢复项追加序号，避免覆盖现有内容。永久删除不可通过普通界面撤销，执行前应确认备份可用。

## 版本记录

创建新版本、覆盖策略或内容更新可能产生历史版本。管理员可设置版本保留数量和保留天数。恢复历史版本会把指定版本重新设为当前内容，并留下审计记录。

## 配额不足

上传被配额阻止时，检查：

- 当前用户配额。
- 工作区配额。
- 存储策略上限。
- 本地磁盘或对象存储实际可用容量。

删除普通文件后，空间可能仍被回收站或历史版本占用。需要释放空间时，同时检查生命周期策略和版本记录。
