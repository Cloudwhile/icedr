# 下载限制与访问验证

外链访问由管理员策略、工作区策略和链接自身设置共同决定。界面会显示最终生效的验证方式、等待时间、限速、有效期以及下载次数。

## 验证方式

| 方式 | 访客操作 | 适合场景 |
| --- | --- | --- |
| 公开访问 | 直接打开链接 | 低敏感、短期公开内容 |
| 邮箱验证 | 输入邮箱并填写验证码 | 需要确认访问邮箱或限制域名 |
| 登录访问 | 使用站点账号或 OAuth 登录 | 只允许已知账号访问 |

工作区成员可能根据管理员策略跳过部分等待或重复验证，但不应据此判断外部访客的实际体验。

## 邮箱验证码

1. 输入允许的邮箱地址。
2. 获取验证码并在有效期内提交。
3. 验证成功后，当前浏览器获得该分享的临时访问会话。

收不到验证码时：

- 确认邮箱拼写和允许域名。
- 检查垃圾邮件和邮件延迟。
- 不要连续频繁点击发送，避免触发限流。
- 联系管理员检查 SMTP 测试和投递日志。

验证码多次错误会触发临时锁定。等待页面提示的时间后再重试，不要不断刷新或更换大小写形式的同一邮箱。

## 等待时间与限速

等待时间用于延迟下载准备，倒计时结束前不能开始下载。刷新页面通常不会绕过服务端判断。

限速可能由管理员统一设置。浏览器显示的瞬时速度还会受到源站带宽、对象存储、反向代理和客户端网络影响。

## 次数与有效期

- 查看次数达到上限后，链接会停止提供内容。
- 下载次数在正式开始下载时计数；重复开始或多个访客会共同消耗共享额度。
- 到达过期时间或链接被撤销后，已有页面也不能继续创建新的预览或下载。
- 文件被移入回收站、永久删除或移出分享范围后，原链接可能失效。

## 常见提示

| 页面提示 | 含义 | 建议 |
| --- | --- | --- |
| 需要验证 | 尚未建立有效访问会话 | 按页面完成邮箱或账号验证 |
| 邮箱不允许 | 邮箱或域名不在允许范围 | 使用获授权邮箱或联系管理员 |
| 下载已禁用 | 分享策略不允许下载 | 使用预览或联系分享创建者 |
| 等待时间未结束 | 服务端仍在计时 | 保持页面打开并等待 |
| 链接不可用 | 链接不存在、已撤销或已过期 | 向分享创建者索取新链接 |
| 次数已用尽 | 查看或下载达到上限 | 由分享创建者重新创建或调整策略 |
| 请求过于频繁 | 触发访问、验证码或下载限流 | 停止重试并等待限制窗口结束 |

对应状态码见 [错误码参考](/reference/error-codes)。
