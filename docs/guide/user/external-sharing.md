# 外链分享

外链用于把工作区内的文件或文件夹提供给工作区之外的访客。分享创建者只能在管理员允许的范围内设置访问、预览、下载和有效期，不能放宽组织级限制。

## 创建外链

1. 在文件列表中选择一个文件、文件夹或多个文件。
2. 打开分享操作，选择“创建外链”。
3. 填写备注，并确认分享范围。
4. 检查访问方式、预览、下载、有效期和次数限制。
5. 创建后复制链接，并使用无痕窗口验证。

分享模式：

| 模式 | 可见内容 |
| --- | --- |
| 单个文件 | 仅所选文件 |
| 多文件快照 | 仅创建分享时选中的条目，同目录其他文件不可见 |
| 文件夹分享 | 所选文件夹及其分享范围内的后代内容 |

## 访问方式

- 公开访问：访客无需账号；仍可能受到等待时间、限速和次数限制。
- 邮箱验证：访客输入邮箱并通过验证码后访问，可限制允许的邮箱域名。
- 登录访问：访客使用站点账号或已启用的 OAuth 身份访问。

管理员可以禁止匿名访问或强制邮箱验证。最终访问方式以外链页面实际显示为准。

## 权限与限制

创建前重点确认：

- 是否允许在线预览。
- 是否允许下载。
- 链接何时过期。
- 最大查看或下载次数。
- 是否需要等待后才能下载。
- 是否应用限速。

“允许预览”和“允许下载”互相独立。禁止下载不一定禁止浏览器预览；禁止预览时也可以按策略保留下载。

## 测试分享

不要只在已登录的管理员浏览器中测试。推荐：

1. 复制链接到无痕窗口。
2. 验证匿名、邮箱或登录流程。
3. 打开一个可预览文件。
4. 在允许的情况下完成一次下载。
5. 返回管理面板检查审计记录和访问次数。

## 管理与撤销

“外链分享”页面可以查看链接状态、过期时间、访问和下载次数。链接不再需要时应主动关闭，而不是只等待过期。

撤销后，原链接会显示不可用。撤销不会删除源文件；删除或归档源文件则可能使分享内容不可访问。

## 安全建议

- 敏感内容优先使用邮箱验证或登录访问。
- 有明确协作周期时设置短有效期。
- 下载次数限制不等于数字版权保护；访客取得文件后仍可能自行复制。
- 不要通过公开渠道同时发送链接和验证邮箱的控制权。
- 定期检查长期有效、访问量异常或无人负责的外链。

访问验证和限制的具体行为见 [下载限制与访问验证](/guide/user/download-access)。
