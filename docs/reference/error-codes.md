# 错误码参考

本页解释产品界面、反向代理和日志中可能出现的状态码与业务错误码，用于定位登录、上传、外链和存储问题。

## 状态码

| 状态码 | 用户可见含义 | 常见场景 |
| --- | --- | --- |
| `400` | 输入或当前操作不符合规则 | 非法文件名、缺少配置、参数组合无效 |
| `401` | 登录或最近认证已失效 | 会话过期、需要重新认证、敏感操作中的恢复码无效 |
| `403` | 当前身份或策略不允许 | 下载被禁用、邮箱域名不允许、管理员权限不足 |
| `404` | 目标不存在 | 文件、分享、版本或传输记录已不存在 |
| `409` | 状态冲突 | 邮箱已注册、同名目标冲突、上传策略要求跳过 |
| `410` | 目标曾存在但已失效 | 分享已撤销、已过期、次数已用尽、文件已归档 |
| `413` | 请求体超过代理限制 | Nginx、CDN 或 WAF 拒绝大文件上传 |
| `422` | 表单验证失败 | 字段格式或组合不符合要求 |
| `429` | 请求过于频繁 | 验证码、登录、分享查看或下载触发限流 |
| `500` | 服务内部错误 | 未处理异常、数据库或存储操作失败 |
| `502` / `504` | 代理无法连接或等待超时 | ICEDR 未运行、上游地址错误、上传下载超时 |
| `503` | 依赖暂时不可用 | 数据库验证失败、服务启动未就绪 |

`413`、`502` 和 `504` 经常由反向代理产生，不一定来自 ICEDR 本身。

## 认证业务错误码

| 错误码 | 含义 | 处理方式 |
| --- | --- | --- |
| `AUTH_REAUTH_REQUIRED` | 敏感操作需要最近认证 | 按提示重新输入密码、使用 Passkey 或恢复方式 |
| `AUTH_REAUTH_FAILED` | 重新认证失败 | 检查凭据，等待限流窗口后重试 |
| `AUTH_REAUTH_METHOD_UNAVAILABLE` | 当前没有可用的重新认证方式 | 保留至少一种可用于敏感操作验证的认证方式 |
| `AUTH_METHOD_POLICY_REQUIRED` | 管理策略要求指定认证方式 | 使用管理员允许的方法完成认证 |
| `AUTH_RECOVERY_CODE_INVALID` | 敏感操作使用的恢复码无效或已使用 | 在已登录会话中使用未使用的恢复码，或改用其他验证方式 |
| `AUTH_LAST_LOGIN_METHOD` | 操作会删除最后一种登录方式 | 先启用并验证另一种登录方式 |
| `PASSKEY_CEREMONY_UNAVAILABLE` | 浏览器无法开始 Passkey 流程 | 检查 HTTPS、RP ID、Origin 和浏览器支持 |
| `PASSKEY_VERIFICATION_FAILED` | Passkey 验证未通过 | 使用正确设备，检查系统时间和站点 Origin |

## 外链错误判断

### `403` 与 `410` 的区别

- `403`：链接仍存在，但当前身份、等待时间、预览或下载策略不允许这次操作。
- `410`：链接已经撤销、过期、达到次数上限，或内容已不再可用。

### `404` 与 `410` 的区别

- `404`：无法找到对应目标，页面不会确认它是否曾经存在。
- `410`：系统知道目标已经失效，可以向访客显示更明确的不可用状态。

### `429`

停止自动刷新和连续提交。等待限制窗口结束后再试。验证码错误次数达到上限时，继续输入不会提前解除锁定。

## 文件冲突

文件名冲突返回 `409`：

- 创建文件夹、重命名、移动或复制到已有同名目标时，操作会被拒绝。
- 上传选择“跳过”时，冲突项不会创建上传任务。
- 上传选择“自动重命名”“覆盖”或“创建新版本”时，按界面显示的最终结果处理。

文件名规则见 [上传与文件管理](/guide/user/file-management#文件名规则)。

## 向管理员提供排障信息

提供以下内容即可，不要发送密码、Secret、验证码、Cookie 或完整连接串：

- 发生时间和时区。
- 页面与操作步骤。
- 状态码和业务错误码。
- 已脱敏的错误提示。
- 相关审计日志 ID。
- ICEDR 版本和部署方式。

问题定位流程见 [故障排查](/reference/troubleshooting)。
